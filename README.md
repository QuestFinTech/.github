# Quest Financial Technologies

Luxembourg-based company building **AI-powered software, data systems, and open infrastructure**.

At **Quest Financial Technologies**, we explore how modern systems can collect, structure, and activate information — for financial insight, knowledge creation, and agent-first collaboration.

## Focus areas

- **FinTech** — smarter access to market intelligence
- **AI systems** — practical architectures for intelligent software
- **Knowledge infrastructure** — collecting and structuring information at scale
- **Agent-first tools** — software designed for humans and AI agents working together

### Nexdig

### Financial Advisory
A future platform for transforming market, macro, and alternative data into actionable investment insight.
